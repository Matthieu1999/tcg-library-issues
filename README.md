# TCG Library — Issue Tracker

Public bug tracker and feature-request board for **TCG Library**, an app for
managing Pokémon TCG and Magic: The Gathering collections.

The app's source code is private. This repository holds no code — it exists so
that anyone can report a problem or suggest something without needing access to
the source.

## Report something

| | |
|---|---|
| 🐛 **Found a bug?** | [Open a bug report](../../issues/new?template=bug_report.yml) |
| ✨ **Want a feature?** | [Open a feature request](../../issues/new?template=feature_request.yml) |
| 💬 **Just a question?** | [Start a discussion](../../discussions) |
| 🔒 **Security problem?** | [Report it privately](../../security/advisories/new) — never in a public issue |

## Before you open an issue

- **Search [existing issues](../../issues?q=is%3Aissue) first.** A 👍 on an
  existing report is more useful than a duplicate — it tells me what to
  prioritise.
- **Include your app version and platform.** The version is in
  **Settings → About**. Without it, "it doesn't work" is usually unactionable.
- **One issue per report.** Three bugs in one thread means two of them get
  forgotten.

## Please don't post

Issues here are **public and permanently indexed**. Before attaching a
screenshot or a log, check it doesn't contain:

- your email address or username
- authentication tokens, session ids or password-reset links
- anything else you wouldn't post on a public forum

Redact them, or describe the problem in words instead.

## What happens next

Issues are triaged by hand by one person, so replies aren't instant. Accepted
reports are moved into the private development repository for the actual work,
and the issue here is updated and closed when the fix ships. A closed issue with
a linked release is a fixed issue.
